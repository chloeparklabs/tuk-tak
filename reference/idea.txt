규모에 따라 세 단계 정도로 나눠서 볼 수 있어요.

1단계 — 순수 HTML/CSS/JS 단일 파일 (가장 간단)
말씀하신 기능(한국어 노출 → 정답보기 버튼 → 영어 노출)에는 프레임워크가 필요 없어요. 위 파일이 실제로 그 스펙으로 만든 프로토타입입니다.

문장 데이터: JS 배열에 {kr, en} 형태로 저장
저장: localStorage로 문장 목록과 진행 상태 유지 (앱 안의 "문장 편집"에서 직접 추가/수정 가능)
배포: 파일 하나라서 그대로 열어도 되고, Vercel/Netlify에 정적 파일로 올려도 됨
폰에서 스페이스바 대신 화면 탭으로 정답보기/다음카드 넘김, 셔플 기능도 넣어봤어요

2단계 — PWA로 확장 (spark 메모앱과 같은 패턴)
지금 만드신 spark처럼 manifest.json + service worker만 추가하면 폰 홈화면에 앱처럼 설치되고 오프라인에서도 동작해요. 지하철에서 인터넷 없이 암기할 때 유용합니다.

3단계 — Supabase + Vercel (여러 기기 동기화 / 학생 배포까지 고려한다면)
게시판 프로젝트와 같은 스택이에요. 이게 필요한 경우는:

폰/PC 등 여러 기기에서 같은 진행 상태를 보고 싶을 때
학생들에게 나눠주고 각자 학습 기록(정답률, 오답노트)을 서버에 쌓고 싶을 때
문장 데이터를 엑셀로 관리하다가 앱에서 CSV/엑셀 업로드로 불러오고 싶을 때 (papaparse 또는 SheetJS)

넣으면 좋은 확장 기능 아이디어

오답 카드만 다시 보기 (틀린 것 표시 → 재출제)
스페이스드 리피티션 (SM-2 알고리즘): 맞은 문장은 점점 간격을 늘려서 복습, 망각곡선 기반 학습
발음/듣기까지 원하면 Web Speech API로 영어 문장 TTS 재생 (spark에서 쓰신 음성 API와 같은 계열)

지금 만든 프로토타입은 1단계 스펙으로, 카드에 있는 "문장 편집" 버튼에서 원하는 한국어-영어 쌍을 직접 넣고 바로 써보실 수 있어요. 2단계(PWA), 3단계(Supabase 연동)로 넘어가고 싶으시면 이 파일을 기반으로 이어서 확장해드릴 수 있습니다.
