AI 자동변형(15-2) — 현재 사용 중인 프롬프트 전체
작성일: 2026-09-19
출처: js/app.js의 buildAiVariationPrompt() + api/generate-variations.js의 AI_VARIATION_SYSTEM_PROMPT

이 문서는 "지금 실제로 서버에 전달되는 프롬프트가 정확히 뭔지" 확인/공유용으로 만든 스냅샷입니다.
프롬프트 원본은 코드(js/app.js)에 있으니, 이후 프롬프트가 바뀌면 이 파일은 갱신하거나 참고용으로만 볼 것.


===========================================================
1. 시스템 프롬프트 (api/generate-variations.js, AI_VARIATION_SYSTEM_PROMPT)
===========================================================
역할/출력 규칙만 여기서 강제하고, 실제 과제 내용(원문·요청 종류·판단 기준)은 아래 2번(사용자 메시지)에 담겨 있음.

당신은 한국어-영어 문장 변형을 만드는 전문가입니다. 사용자 메시지에 담긴 원문과 요청 사항, 예외 규칙에 따라 자연스러운 변형 문장들을 만드세요. 반드시 submit_variations 도구를 호출해서만 답하고, 그 외의 설명이나 텍스트는 절대 덧붙이지 마세요.


===========================================================
2. 사용자 메시지 프롬프트 (js/app.js, buildAiVariationPrompt())
===========================================================
아래 {한국어 문장}/{English sentence} 자리에 실제 원문이 들어감. 예시로 "커피 마시고 싶다 / I want to have a coffee."를 넣은 버전을 함께 적어둠.

--- 템플릿 (그대로) ---

다음 한국어-영어 문장을 아래 9가지 방식으로 변형해줘.

변형을 만들기 전에 매번 "원어민이 실제 대화에서 이렇게 말할까?"를 스스로 판단해라. 문법적으로는 성립해도 실제로는 어색하거나 잘 안 쓰는 표현이면 그 변형은 만들지 마라 — 누군가 어떤 문장을 보여주며 "이거 자연스러운 표현이야?"라고 물었을 때처럼 판단하면 된다. 아래는 그 판단 기준의 대표적인 예시일 뿐이니, 목록에 없는 경우에도 같은 기준으로 스스로 걸러라:

- 인사/감사/사과 등 고정 관용표현 → 시제·의문문 변형 생략 (예: "안녕하세요" / "Hello.")
- 비인칭 주어 문장(날씨, "~이 있다" 등) → 인칭(2인칭/3인칭 단수) 변형 생략 (예: "비가 온다" / "It's raining.", "책상 위에 책이 있다" / "There is a book on the desk.")
- 청유문/명령문("~하자") → 시제 변형 생략 (예: "같이 가자" / "Let's go.")
- 문장에 이미 시간부사(어제/내일/지금 등)가 있는 경우 → 그 시간부사와 충돌하는 시제 변형 생략 (예: "어제 학교에 갔다" / "I went to school yesterday." → 미래시제 생략)
- 이미 부정 의미를 내포한 관용구("전혀 모르겠다" 등) → 부정문 변형 생략(이중부정 방지)
- "유일한", 고유명사 주어 등 복수화가 논리적으로 성립 안 되는 경우 → 복수 변형 생략 (예: "나는 외동이다" / "I am the only child.")
- 감탄문("~구나!") → 의문문 변형 생략(뉘앙스가 사라지고 의미가 바뀜)
- 즉흥적 욕구·감정·신체상태 표현("~하고 싶다", "피곤하다", "졸리다" 등)은 "오랫동안/쭉" 같은 지속 기간 표현이 없으면 현재완료로 쓰면 부자연스러움 → 현재완료 변형 생략 (예: "커피 마시고 싶다" / "I want to have a coffee.")

판단이 끝나면, 자연스럽다고 확인된 변형만 아래 형식으로 출력해라: 각 줄에 "한국어 문장" 다음 탭(Tab)을 하나 넣고 이어서 "English sentence"를 쓰는 형식으로, 결과를 코드블록 안에 한 줄에 하나씩만 적어줘(설명 없이 결과만).

원문: {한국어 문장} / {English sentence}

변형 요청: 현재시제, 과거시제, 미래시제, 현재완료시제, 2인칭, 3인칭 단수, 복수, 부정문, 의문문

===========================================================
3. 출력 형식 강제 (JSON tool-forcing, api/generate-variations.js)
===========================================================
위 텍스트 프롬프트와 별개로, Claude API 호출 시 아래 도구(tool) 호출을 강제해서 형식 이탈(코드블록 누락 등)을 API 차원에서 막고 있음. 모델은 이 스키마를 만족하는 함수 호출로만 답할 수 있고, 서버가 그 결과를 다시 "한국어\t영어" 텍스트로 재조립해 클라이언트에 돌려줌.

도구 이름: submit_variations
입력 스키마:
  variations: 배열
    각 항목:
      label: 다음 9개 중 하나 — "현재시제", "과거시제", "미래시제", "현재완료시제", "2인칭", "3인칭 단수", "복수", "부정문", "의문문"
      kr: 변형된 한국어 문장 (문자열)
      en: 변형된 영어 문장 (문자열)
