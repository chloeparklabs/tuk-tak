  ---
  비용

  Firebase Hosting 자체는 무료(Spark 요금제로 충분 — 저장용량 10GB, 전송량 하루 360MB까지 무료, 지금 트래픽 규모론 남음).

  문제는 Cloud Functions: generate-variations.js가 Claude API(Anthropic 외부 서버)를 호출하는데, 이런 외부 네트워크 호출은 무료 Spark 요금제에서 아예 막혀 있고
  Blaze(종량제) 요금제로 업그레이드해야 가능합니다.

  - Blaze는 "종량제"지만 그 안에도 매달 무료 할당량이 있습니다: 함수 호출 월 200만 건, 외부 네트워크 전송 월 5GB까지 무료. 지금 AI 변형 기능 사용량(평생 100개 한도짜리  기능, 사용자도 적음) 규모로는 사실상 과금 0원일 가능성이 매우 높습니다.
  - 다만 Blaze로 올리려면 구글 계정에 신용카드를 등록해야 합니다(사업자등록은 불필요, 개인 카드면 됨 — 지금까지 지켜온 "사업자등록 불필요" 원칙과 충돌 없음). 카드 등록  자체가 비용은 아니지만, 버그로 호출이 폭주하는 등 예상 밖 상황이면 과금될 수 있다는 점은 Vercel(한도 넘으면 그냥 멈춤)과 다른 리스크입니다. 지금 규모론 거의 걱정 안  해도 되는 수준이긴 합니다.

  1. Firebase 콘솔에서 Blaze 요금제로 업그레이드(카드 등록)
  2. npm install -g firebase-tools + firebase login
  3. ANTHROPIC_API_KEY 등 환경변수를 Firebase 쪽에 재등록
  4. 배포 명령 실행(제가 정확한 명령어 안내)
  5. Firebase Auth "승인된 도메인" + Google OAuth 동의화면에 새 도메인 추가
