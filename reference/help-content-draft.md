## 2. 카드 학습 화면

- **이전 / 확인 / 다음**: 카드 학습의 기본 조작. "확인"을 누르면 영어 정답이 나타남
- **정답을 확인한 뒤 나타나는 아이콘**
  - ☆ 중요 표시 (다시 봐야 할 문장 즐겨찾기)
  - ⚑ 미암기 표시 (아직 못 외운 문장 표시)
  - ✏ 수정 (오탈자 등을 바로 고치기)
  - 🗑 삭제
- **이어보기**: 앱을 껐다 켜도 마지막으로 보던 문장부터 자동으로 이어서 시작함
- **처음부터**: 앱을 끄지 않고도 첫 문장부터 다시 보고 싶으면 더보기 메뉴의 "처음부터" 사용

## 3. 문장 추가하기

문장추가 모달에서 3가지 방법 중 선택:

1. **폼 입력**: 한국어/영어 문장을 하나씩 직접 입력
2. **파일 가져오기**: 엑셀·구글시트·메모장 등에서 "한국어 [구분] 영어" 형태로 여러 줄 작성 → CSV/TSV/TXT로 저장 → 업로드
   - 구분자는 자동 인식됨 (탭 → 쉼표 → 연속 공백 2칸 이상 순서로 시도)
   - 첫 줄이 "한국어"/"kr"/"korean" 같은 헤더면 자동으로 건너뜀
3. **텍스트 붙여넣기**: 파일로 저장하지 않고 텍스트를 바로 붙여넣어 한 번에 여러 문장 추가 (ChatGPT 등에서 만든 문장 붙여넣을 때 유용). 구분자·헤더 규칙은 파일 가져오기와 동일

> 문장관리 목록을 탭하거나 카드 화면의 ✏ 아이콘을 누르면 같은 입력창이 "수정 모드"로 열림

### 3-1. 텍스트 파일 만드는 법 (자세히)

**메모장(Windows 기본 앱)으로 만들기**

1. 메모장을 실행한다
2. 한 줄에 문장 하나씩, "한국어 문장" 다음 **Tab 키**를 누르고 이어서 "English sentence"를 입력한다 (문장마다 줄바꿈으로 구분)
   - 예시
     ```
     오늘 날씨가 어때?	How is the weather?
     나는 커피를 좋아해.	I like coffee.
     ```
   - 스마트폰 메모장 앱 등에서 탭 입력이 안 되거나 붙여넣기 과정에서 탭이 스페이스로 바뀌어도 괜찮음 — 앱이 연속된 공백 2칸 이상도 구분자로 자동 인식함(한 칸 띄어쓰기는 문장의 일부로 보고 구분자로 보지 않음)
3. 메뉴에서 **파일 > 다른 이름으로 저장**을 누른다
4. "파일 형식"을 **모든 파일**로 바꾼다 (기본값인 "텍스트 문서"로 두면 뒤에 `.txt`가 중복으로 붙을 수 있음)
5. 파일 이름 끝에 **`.txt`**를 직접 붙인다 (예: `내문장.txt`)
6. "인코딩"을 반드시 **UTF-8**로 선택한다 — 다른 인코딩으로 저장하면 앱에서 불러올 때 한글이 깨져 보일 수 있음
7. 저장 버튼을 누르면 완료. 이 파일을 "문장추가 > 파일 가져오기"에서 선택하면 됨

**엑셀/구글시트로 만들기**

1. A열에는 한국어 문장, B열에는 영어 문장을 한 줄에 하나씩 입력한다 (첫 줄에 "한국어" / "영어" 같은 제목을 적어도 되고, 자동으로 건너뜀)
2. 저장할 때
   - 엑셀: **파일 > 다른 이름으로 저장** → 파일 형식에서 **CSV UTF-8(쉼표로 분리)(.csv)** 선택
   - 구글시트: **파일 > 다운로드 > 쉼표로 구분된 값(.csv)** 선택
3. 문장 안에 쉼표(,)가 들어가는 경우(예: "Yesterday, I went home.") CSV는 그 쉼표까지 구분자로 오인해 깨질 수 있으므로, 이런 문장이 많다면 위 메모장 방법(Tab 구분, TSV)을 추천

**공통 주의사항**

- 파일 확장자는 `.csv` / `.tsv` / `.txt` 중 아무거나 상관없음 (내용 구분자만 맞으면 됨)
- 첫 줄이 "한국어", "kr", "korean" 같은 헤더로 보이면 자동으로 건너뛰므로 표 제목 줄을 지우지 않아도 됨
- 저장 후 앱에서 "N개 문장을 추가했습니다"로 뜨는 개수가 0이면, 대부분 구분자(탭/쉼표)나 인코딩 문제이니 위 순서를 다시 확인

## 4. 문장 관리하기

- **문장관리** 화면에서 전체 문장 목록을 확인
- 항목을 탭하면 수정, 길게 누르면 해당 문장만 삭제 확인
- 상단 "선택" 버튼으로 여러 문장을 체크해 한 번에 삭제 가능 (최소 1개는 항상 남아 있어야 함)
- **필터**: 전체 / 중요 / 미암기 탭으로 조건에 맞는 문장만 보기. 탭 아래에 현재 보고 있는 문장 개수도 함께 표시됨

---

## 5. 설정

- **글자크기**: 카드 텍스트 크기를 5단계로 조절 (예시 글자 "가"로 실시간 확인)
- **화면모드**: 시스템 / 라이트 / 다크 중 선택. "시스템"은 기기 설정을 실시간으로 따라감
- **출제/정렬 순서**: 아래 5가지 중 선택
  - 랜덤순
  - 최신순
  - 오래된순 (기본값)
  - 못외운것 먼저
  - 중요한것 먼저
- **데이터 관리**
  - 백업 내보내기: 현재 문장을 TSV 파일로 다운로드
  - 초기화: 문장을 모두 삭제 (다른 설정값은 유지됨). 되돌리려면 백업 TSV 파일을 "문장추가 > 파일 가져오기"로 다시 불러오면 됨

## 6. 학습법 — 툭탁을 효과적으로 쓰는 법 (2026-09-03 초안 추가, 착수 전)

### 왜 소리 내어 말해야 하나요?
- 텍스트로 눈으로 확인만 하는 것과 실제로 소리 내어 말해보는 것은 다른 능력입니다. "이해했다"와 "말할 수 있다"는 별개입니다
- 카드에서 정답을 보기 전에, 먼저 소리 내어 말해보고 나서 확인해보세요
- 정답을 확인한 뒤에도 한 번 더 따라 읽으면 훨씬 오래 남습니다

### 왜 내가 고른 문장이어야 하나요?
- 남이 만든 예문은 나와 상관없는 상황이라 기억에 잘 안 남습니다. 내가 실제로 쓸 상황을 담은 문장은 오래갑니다
- 문장을 넣을 때, 실제로 그 말을 할 상황을 한번 떠올리면서 넣어보면 더 잘 외워집니다
- 툭탁이 기본문장보다 "내 문장 넣기"를 중심 기능으로 둔 이유이기도 합니다

### 반복 학습을 효과적으로 쓰는 팁
- 한 번에 몰아보는 것보다, 짧게(5~10분) 여러 번 나눠 보는 쪽이 기억에 더 잘 남습니다
- 설정의 "못외운것 먼저" 정렬을 쓰면 자꾸 틀리는 문장을 더 자주 마주치게 됩니다
- "중요한것 먼저"로 급하게 필요한 문장부터 우선 볼 수 있습니다
- 며칠 뒤 다시 봤을 때 바로 안 떠올라도 자연스러운 과정입니다 — 다시 마주치는 것 자체가 학습입니다
