도움말
  • 이전 / 확인 / 다음: 카드 학습의 기본 조작. "확인"을 누르면 영어 정답이 나타남
  • 정답을 확인한 뒤 나타나는 아이콘
    • ☆ 중요 표시 (다시 봐야 할 문장 즐겨찾기)
    • ⚑ 미암기 표시 (아직 못 외운 문장 표시)
    • ✏ 수정 (오탈자 등을 바로 고치기)
    • 🗑 삭제
  • 이어보기: 앱을 껐다 켜도 마지막으로 보던 문장부터 자동으로 이어서 시작함
  • 처음부터: 앱을 끄지 않고도 첫 문장부터 다시 보기

문장추가 모달에서 3가지 방법 중 선택:

  1. 폼 입력: 한국어/영어 문장을 하나씩 직접 입력
  2. 텍스트 붙여넣기: 파일로 저장하지 않고 텍스트를 바로 붙여넣어 한 번에 여러 문장 추가
    • 한국어와 영어를 탭으로 구분해 엑셀·메모장 등에 작성한 뒤, 텍스트를 복사해서 붙여넣기 (예: 한국어 [탭] 영어)
    • 손으로 영작한 노트는 사진으로 찍어 AI에게 보여주고 아래 프롬프트를 사용하면 쉽게 텍스트로 옮길 수 있음 
      사진 속 문장들을 한국어를 먼저, 영어를 나중에 쓰고 그 사이를 탭으로 구분해서 한 줄에 한 문장씩 정리해줘.
코드블록으로 써줘
  3. 파일 가져오기: 메모장이나 엑셀 등에서 한국어와 영어를 탭으로 구분해 작성한 뒤, .csv / .tsv / .txt 형식으로 저장해서 가져오기
    텍스트 파일 만드는 법

    메모장(Windows 기본 앱)으로 만들기

    1. 메모장을 실행한다
    2. 한 줄에 문장 하나씩, "한국어 문장" 다음 Tab 키를 누르고 이어서 "English sentence"를 입력한다 (문장마다 줄바꿈으로 구분) 
      오늘 날씨가 어때?	How is the weather?
나는 커피를 좋아해.	I like coffee.
      스마트폰 메모장 등에서 탭이 스페이스로 바뀌어도 괜찮음 — 연속 공백 2칸 이상도 구분자로 자동 인식됨
    3. 메뉴에서 파일 > 다른 이름으로 저장을 누른다
    4. "파일 형식"을 모든 파일로 바꾼다 (기본값인 "텍스트 문서"로 두면 뒤에 .txt가 중복으로 붙을 수 있음)
    5. 파일 이름 끝에 .txt를 직접 붙인다 (예: 내문장.txt)
    6. "인코딩"을 반드시 UTF-8로 선택한다 — 다른 인코딩으로 저장하면 한글이 깨져 보일 수 있음
    7. 저장 버튼을 누르면 완료. 이 파일을 "문장추가 > 파일 가져오기"에서 선택하면 됨

    엑셀/구글시트로 만들기

    1. A열에는 한국어 문장, B열에는 영어 문장을 한 줄에 하나씩 입력한다 (첫 줄에 제목을 적어도 자동으로 건너뜀)
    2. 저장할 때
      • 엑셀: 파일 > 다른 이름으로 저장 → 파일 형식에서 CSV UTF-8(쉼표로 분리)(.csv) 선택
      • 구글시트: 파일 > 다운로드 > 쉼표로 구분된 값(.csv) 선택
    3. 문장 안에 쉼표(,)가 들어가는 경우 CSV가 깨질 수 있어, 이런 문장이 많다면 위 메모장 방법(Tab 구분)을 추천

    공통 주의사항

    • 파일 확장자는 .csv / .tsv / .txt 중 아무거나 상관없음 (내용 구분자만 맞으면 됨)
    • 첫 줄이 "한국어", "kr", "korean" 같은 헤더로 보이면 자동으로 건너뜀
    • "N개 문장을 추가했습니다"의 개수가 0이면 대부분 구분자·인코딩 문제이니 위 순서를 다시 확인
  • 문장관리 화면에서 전체 문장 목록을 확인
  • 항목을 탭하면 수정, 길게 누르면 해당 문장만 삭제 확인
  • 상단 "선택" 버튼으로 여러 문장을 체크해 한 번에 삭제 가능 (최소 1개는 항상 남아 있어야 함)
  • 필터: 전체 / 중요 / 미암기 탭으로 조건에 맞는 문장만 보기. 탭 아래에 현재 보고 있는 문장 개수도 함께 표시됨
  • 글자크기: 카드 텍스트 크기를 5단계로 조절 (예시 글자 "가"로 실시간 확인)
  • 화면모드: 시스템 / 라이트 / 다크 중 선택. "시스템"은 기기 설정을 실시간으로 따라감
  • 출제/정렬 순서: 랜덤순 · 최신순 · 오래된순(기본값) · 못외운것 먼저 · 중요한것 먼저 중 선택
  • 데이터 관리
    • 백업 내보내기: 현재 문장을 TSV 파일로 다운로드
    • 초기화: 문장을 모두 삭제 (다른 설정값은 유지됨). 되돌리려면 백업 TSV 파일을 "문장추가 > 파일 가져오기"로 다시 불러오면 됨
  • 클라우드 백업: Google 계정으로 로그인하면 문장을 클라우드에 백업하고 다른 기기에서 복원 가능. 자세한 수집 정보는 아래 "개인정보처리방침" 참고

Tuk Tak은 기본적으로 모든 학습 문장을 여러분의 기기 안(로컬 저장소)에만 보관합니다. 아래 내용은 Google 로그인으로 클라우드 백업 기능을 사용할 때만 적용됩니다.

  • 수집하는 정보
    • Google 계정의 이메일 주소 (로그인 확인용)
    • 입력하신 학습 문장(한국어/영어 텍스트) — "지금 백업"을 눌렀을 때만 전송됨
  • 저장 위치: Google Firebase(Firestore), 서울 리전 서버
  • 이용 목적: 로그인한 본인 확인, 문장 데이터의 클라우드 백업 및 복원
  • 제3자 제공: 없음 — 광고나 분석 목적으로 이용하거나 제3자와 공유하지 않음
  • 보관 기간: 로그아웃해도 클라우드에 백업된 데이터는 삭제되지 않고 남아 있어, 다시 로그인하면 복원할 수 있습니다. 삭제를 원하시면 아래 문의처로 연락해 주세요
