TUK TAK

사용 가이드 & 효과적으로 외우는 법

내가 직접 넣은 문장을, 완벽하게 외울 때까지 반복해서 익히는 앱입니다. 남이 정해준 예문이 아니라 내가 실제로 쓸 문장을, "툭" 치면 "탁" 나올 때까지 암기하세요.

효과적으로 외우는 법

왜 소리 내어 말해야 하나요?

텍스트를 눈으로 확인만 하는 것과 실제로 소리 내어 말해보는 것은 다른 능력입니다. "이해했다"와 "말할 수 있다"는 별개입니다.

  • 카드에서 정답을 보기 전에, 먼저 소리 내어 말해보고 나서 "확인"을 눌러보세요
  • 정답을 확인한 뒤에도 한 번 더 따라 읽으면 훨씬 오래 남습니다 — 스피커 아이콘으로 정확한 발음을 들으며 따라 하면 더 좋습니다

왜 내가 고른 문장이어야 하나요?

남이 만든 예문은 나와 상관없는 상황이라 기억에 잘 남지 않습니다. 내가 실제로 쓸 상황을 담은 문장은 오래갑니다.

  • 문장을 넣을 때, 실제로 그 말을 할 상황을 한번 떠올리면서 넣어보면 더 잘 외워집니다
  • Tuk Tak이 정해진 예문보다 "내 문장 넣기"를 중심 기능으로 둔 이유이기도 합니다

반복 학습을 효과적으로 쓰는 팁

  • 한 번에 몰아보는 것보다, 짧게(5~10분) 여러 번 나눠 보는 쪽이 기억에 더 잘 남습니다
  • 설정의 "못외운것 먼저" 정렬을 쓰면 자꾸 틀리는 문장을 더 자주 마주치게 됩니다
  • "중요한것 먼저"로 급하게 필요한 문장부터 우선 볼 수 있습니다
  • 며칠 뒤 다시 봤을 때 바로 안 떠올라도 자연스러운 과정입니다 — 다시 마주치는 것 자체가 학습입니다

사용법

카드 학습 화면
  • 이전 / 확인 / 다음: 카드 학습의 기본 조작. "확인"을 누르거나 문장 텍스트를 탭하면 영어 정답이 나타남
  • 정답을 확인한 뒤 나타나는 아이콘
    • ☆ 중요 표시 (다시 봐야 할 문장 즐겨찾기)
    • ⚑ 미암기 표시 (아직 못 외운 문장 표시)
    • 🔊 발음 듣기
    • ✏ 수정 (오탈자 등을 바로 고치기)
    • 🗑 삭제
  • 이어보기: 앱을 껐다 켜도 마지막으로 보던 문장부터 자동으로 이어서 시작함
  • 처음부터: 설정 화면에서 첫 문장부터 다시 보기
문장 추가하기

문장추가 화면에서 3가지 방법 중 선택할 수 있습니다.

  1. 폼 입력: 한국어/영어 문장을 하나씩 직접 입력
  2. 텍스트로: 파일로 저장하지 않고 텍스트를 바로 붙여넣어 한 번에 여러 문장 추가
    • 한국어와 영어를 탭으로 구분해 엑셀·메모장 등에 작성한 뒤, 텍스트를 복사해서 붙여넣기 (예: 한국어 [탭] 영어)
    • 손으로 쓴 영작 노트는 사진으로 찍어 AI에게 보여주고 아래 프롬프트를 쓰면 쉽게 텍스트로 옮길 수 있습니다 
      사진 속 문장들을 한국어를 먼저, 영어를 나중에 쓰고 그 사이를 탭으로 구분해서 한 줄에 한 문장씩 정리해줘.
코드블록으로 써줘
  3. 파일로: 메모장이나 엑셀 등에서 한국어와 영어를 탭으로 구분해 작성한 뒤, .csv / .tsv / .txt 형식으로 저장해서 가져오기
텍스트 파일 만드는 법(자세히)

메모장(Windows 기본 앱)으로 만들기

  1. 메모장을 실행한다
  2. 한 줄에 문장 하나씩, "한국어 문장" 다음 Tab 키를 누르고 이어서 "English sentence"를 입력한다 
    오늘 날씨가 어때?	How is the weather?
나는 커피를 좋아해.	I like coffee.
    스마트폰 메모장 등에서 탭이 스페이스로 바뀌어도 괜찮습니다 — 연속 공백 2칸 이상도 구분자로 자동 인식됩니다
  3. 메뉴에서 파일 > 다른 이름으로 저장을 누른다
  4. "파일 형식"을 모든 파일로 바꾼다 (기본값인 "텍스트 문서"로 두면 뒤에 .txt가 중복으로 붙을 수 있음)
  5. 파일 이름 끝에 .txt를 직접 붙인다 (예: 내문장.txt)
  6. "인코딩"을 반드시 UTF-8로 선택한다 — 다른 인코딩으로 저장하면 한글이 깨져 보일 수 있습니다
  7. 저장 버튼을 누르면 완료. 이 파일을 "문장추가 > 파일로"에서 선택하면 됩니다

엑셀/구글시트로 만들기

  1. A열에는 한국어 문장, B열에는 영어 문장을 한 줄에 하나씩 입력 (첫 줄에 제목을 적어도 자동으로 건너뜀)
  2. 엑셀은 "다른 이름으로 저장 → CSV UTF-8(쉼표로 분리)", 구글시트는 "다운로드 → 쉼표로 구분된 값(.csv)"으로 저장
  3. 문장 안에 쉼표(,)가 들어가면 CSV가 깨질 수 있어, 그런 경우가 많다면 위 메모장 방법(Tab 구분)을 추천
문장 관리하기
  • 문장관리 화면에서 전체 문장 목록을 확인
  • 항목을 탭하면 수정, 길게 누르면 해당 문장만 삭제 확인
  • 상단 "선택" 버튼으로 여러 문장을 체크해 한 번에 삭제 가능
  • 필터: 전체 / 중요 / 미암기 탭으로 조건에 맞는 문장만 보기
  • 노트형 학습: 카드 없이 문장을 쭉 훑어보며 외우는 화면. "전체 보기 / 한글만 / 영어만"으로 원하는 언어만 볼 수 있고, 자동재생으로 손 안 대고 계속 넘겨볼 수 있음
설정
  • 글자크기: 카드 텍스트 크기를 5단계로 조절
  • 화면모드: 시스템 / 라이트 / 다크 중 선택
  • 출제/정렬 순서: 랜덤순 · 최신순 · 오래된순 · 못외운것 먼저 · 중요한것 먼저 · 한국어순 · 영어순 중 선택
  • 데이터 관리: 백업 내보내기(TSV 파일 다운로드) / 초기화
  • 클라우드 백업: Google 계정으로 로그인하면 문장을 클라우드에 백업하고 다른 기기에서 복원 가능
