Tuk Tak 개인정보처리방침

최종 업데이트: 2026-09-17

Tuk Tak(툭탁)은 기본적으로 모든 학습 문장을 사용자의 기기 안(로컬 저장소)에만 보관합니다. 아래 내용은 Google 로그인으로 클라우드 백업 기능을 사용할 때만 적용됩니다.

수집하는 정보

  • Google 계정의 이메일 주소 (로그인 확인용)
  • 입력하신 학습 문장(한국어/영어 텍스트) — "지금 백업"을 눌렀을 때만 전송됨

저장 위치

Google Firebase(Firestore), 서울 리전 서버

이용 목적

로그인한 본인 확인, 문장 데이터의 클라우드 백업 및 복원

제3자 제공

없음 — 광고나 분석 목적으로 이용하거나 제3자와 공유하지 않습니다.

보관 기간

로그아웃해도 클라우드에 백업된 데이터는 삭제되지 않고 남아 있어, 다시 로그인하면 복원할 수 있습니다. 삭제를 원하시면 아래 "계정 및 데이터 삭제 요청 방법"을 참고해 주세요.

계정 및 데이터 삭제 요청 방법

1. 앱을 사용 중인 경우 (권장, 즉시 처리)
앱 실행 → 더보기(⋮) → 설정 → "클라우드 백업" 섹션 → "클라우드 백업 삭제" 버튼을 누르면 확인 절차 후 즉시 삭제됩니다. 이 기기에 저장된 학습 문장에는 영향이 없습니다.

2. 앱을 이미 삭제했거나 접근할 수 없는 경우
아래 이메일로 "계정 삭제 요청"이라는 제목과 함께, 로그인에 사용하신 Google 계정 이메일 주소를 보내주세요. 확인 후 삭제 처리해 드립니다.

삭제 대상 데이터: Google 계정 이메일 주소, 클라우드에 백업된 학습 문장 전체
추가 보관 기간: 없음 (요청 확인 즉시 삭제)
